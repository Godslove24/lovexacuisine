# Lovexa Cuisine — Website Starter

A responsive, luxury-style restaurant landing website for Lovexa Cuisine, Port Harcourt, Rivers State, Nigeria.

## Run it
1. Unzip this folder.
2. Open the folder in Antigravity.
3. Open `index.html` in a browser, or use a local static server / Live Server extension.
4. In Antigravity, ask the agent to review the project, run it, and improve it without removing the established visual direction.

No build step is required for this static starter.

## Included
- Responsive home, story, menu showcase, experience, gallery, and reservation enquiry sections.
- Responsive mobile navigation.
- Subtle reveal animations with reduced-motion support.
- Reservation form validation and WhatsApp message handoff.
- WhatsApp contact configured for +2349052064461.
- Basic SEO metadata and accessible labels.

## Before publishing
- Replace illustrative stock imagery with licensed photos of the real restaurant and dishes.
- Confirm the actual menu, prices, opening hours, street address, and any claims about services.
- Replace Instagram/Facebook/TikTok placeholder destinations with Lovexa Cuisine's actual profile links.
- Configure a verified map location if desired.
- Test the WhatsApp link on a phone with WhatsApp installed.
- Consider a proper reservation backend if you need bookings to be stored or managed centrally.
